O grupo apresentará o tema jQuery, explicando o que é essa biblioteca, sua relação com JavaScript e para que ela é utilizada. Também serão apresentados seus principais recursos, como seletores, eventos e manipulação de elementos HTML, com exemplos práticos. Em seguida, será realizada uma atividade guiada, com um passo a passo para que a turma possa aprender e praticar os conceitos apresentados, contando com o auxílio do grupo durante a execução. A apresentação seguirá esta ordem: slides no Canva, explicação do conteúdo, demonstração prática, atividade com a turma e apresentação do resultado final.
